# Amazingayo's Expense Tracker 💰

A clean, interactive command-line application written in Java that helps users track their daily expenses, view an itemized list of their purchases, and calculate their total spending in real time.

## ✨ Features
- **Add Expenses:** Record the name/category of an expense alongside its cost.
- **View Expenses:** Display a numbered, formatted list of all recorded expenses in the current session.
- **View Total Spending:** Automatically sum up and display the total amount spent across all recorded items.
- **Interactive Menu:** Runs continuously in a `do-while` loop until the user chooses to exit.

## 🛠️ Built With
- **Java** (JDK)
- `java.util.ArrayList` – For dynamic in-memory storage of expense names (`String`) and amounts (`Double`).
- `java.util.Scanner` – For handling user console input.
